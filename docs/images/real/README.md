# 真机截图（real screenshots）

这个目录用于放**真机截图**——即在实际 DSH 界面里跑本插件时截的图，配合 `docs/images/` 里的**示意图**一起说明功能。

## 为什么现在是空的

示意图（`docs/images/01..06-*.svg`）是按本插件的**真实尺寸与配色**手工绘制的，保证仓库一打开就有图能看懂流程；
但"真机长什么样"还是截图最直观，而截图需要有人在界面上操作并按下快门，所以留在这里等补。

## 欢迎补充（怎么放）

建议按流程编号命名，并保证能对上 README 的分段说明：

| 文件名建议 | 内容 |
|---|---|
| `01-select-toolbar.png` | 选中文字后，工具条「添加到对话」出现在选区正上方 |
| `02-one-line-box.png` | 点「添加到对话」后的一行小输入框 + 圆形 ✓ |
| `03-confirmed-marker.png` | 回车（或点 ✓ / 点框外）确认后，正文出现高亮 + 编号角标 |
| `04-chip.png` | 输入框旁的「批注 ×N」芯片（可含悬停展开的样子） |
| `05-edit-card.png` | 点编号角标后打开的编辑卡（删除 / 取消 / 保存） |
| `06-reply.png` | 发送后模型按 `Annotation 1..N` 逐条回答，编号标签可悬停 |

补充时请注意：

1. **别把私人对话内容截图发上来**——如果截图里有你自己的聊天内容、姓名、路径，请先打码或裁掉；
2. 只截**与本插件相关**的区域（选区、工具条、批注框、芯片、回复里的编号标签），不需要整屏；
3. 建议 PNG，宽度 800–1600px；命名与上表一致，README 里可以直接引用。
